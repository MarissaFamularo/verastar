## Code map and policy boundaries

Each checkpoint directory contains an `implementation.diff.txt` with explicit base/target commits in the manifest. Final-candidate diff covers extraction/raw JSON and schema validation, result-context admission, numeric CI parser, independent checker, summary selection, fail-closed rendering and cache/version wiring. It includes client, pipeline and model/shared-contract changes; tests, frozen fixtures and generated bundles are deliberately omitted. Baseline source snapshots support inspection of unchanged numeric/sanitizer mechanisms. Existing tests are evidence, not authorization to run them.

Exact quote location, numeric relationship verification, semantic model judgment and gate/render/cache policy are different stages. Numeric admission is not semantic proof; a checker approval is not proof of complete primary-outcome coverage. Conversely, withheld output can reflect quote formatting or rigid-context false rejection rather than absent source evidence.
