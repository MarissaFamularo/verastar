VERASTAR · GUIDE

API keys, explained.

Verastar uses Claude, an AI model made by Anthropic, to read and score new papers for you. An API key is how Claude knows the work is for your account. Setting one up takes about five minutes, and you only do it once.

What it is

An API key is a personal passcode that lets software use Claude on your behalf. It looks like a long string of letters starting with sk-ant-. You load prepaid credit on your Anthropic account, and each digest draws a little of it down. There is no subscription and no markup, and spending can never exceed the credit you have loaded.

This is separate from a Claude.ai chat subscription. If you already pay for Claude to chat, you still need an API key for Verastar.

How to get one

  1. Create a free account at platform.claude.com, the Anthropic developer console.
  2. Add credit under Set up billing. New accounts start at $0, and $5 is plenty to start.
  3. Open API keys in the sidebar, click Create key, and copy it. The key is shown only once.
  4. Return to Verastar and paste the key into the box.

Save the key somewhere safe, such as a password manager, if you plan to use Verastar on both your phone and your computer. You will paste it on each. If you lose it, just create another.

What it costs

You pay per use, in fractions of a cent per page of text. A full daily digest, which triages roughly 30 to 50 new abstracts and deep-reads the best few papers, runs about $0.10 to $0.30. Saving and verifying a single paper is a few cents. Daily use adds up to under $10 a month. Because credit is prepaid, Verastar simply stops when it runs out. There are no surprise bills.

Is it safe?

Treat your key like a password. Anyone who has it can spend your credit, so do not share it or email it.

Your browser talks directly to Anthropic using your key. The key is never sent to Verastar's servers. By default it lives only in the browser tab and is cleared when you close it.

If you ever think a key has leaked, delete it in the Anthropic console and create a new one. The old key stops working immediately. Verastar handles published literature only. Never enter patient information anywhere in it.

You can close this tab and return to Verastar when you are ready.
